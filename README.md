# Relay

사내 통합 업무 플랫폼 프로젝트.

## 주요 기능

- 연차 / 반차 신청 및 결재
- 사내 프로그램 버그 / 개선 / 기능 요청
- 개발자 담당 배정 및 이슈 관리
- 사내 채널 및 메시지
- 알림
- 임직원 / 부서 / 권한 관리

## Tech Stack

### Frontend

- React
- TypeScript
- Vite

### Backend

- Python
- FastAPI

### Database

- PostgreSQL

## Architecture

Monorepo

- frontend
- backend
- database
- docs
